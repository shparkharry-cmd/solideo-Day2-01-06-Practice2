# 🌍 TravelMate AI - 나만을 위한 완벽한 여행 비서

> "당신의 취향을 이해하는 AI가 설계하는, 세상에 단 하나뿐인 여행"

## 📌 프로젝트 개요

**TravelMate AI**는 인공지능 기반의 초개인화 여행 플래닝 플랫폼입니다.
단순한 경로 검색을 넘어, 사용자의 취향, 예산, 여행 스타일을 학습하여
완벽하게 맞춤화된 여행 일정을 자동으로 생성해드립니다.

## 🎯 핵심 가치 제안 (Unique Value Proposition)

### 왜 TravelMate AI인가?

| 기존 여행 앱의 문제점 | TravelMate AI의 솔루션 |
|-------------------|---------------------|
| 💔 복잡한 교통편 조합을 직접 찾아야 함 | ✅ AI가 버스·기차·비행기를 최적으로 조합 |
| 💔 맛집·명소 정보가 범람하여 선택 장애 | ✅ 내 취향 기반 개인화된 추천만 제공 |
| 💔 여러 앱을 오가며 정보 조각 모으기 | ✅ 교통·숙박·맛집·관광을 하나의 앱에서 |
| 💔 실시간 변경사항 대응 어려움 | ✅ 실시간 교통 정보 연동 및 자동 경로 재조정 |
| 💔 지도에서 경로만 보여주는 단순 UI | ✅ 3D 시각화 + 타임라인 통합 뷰 |

## 🚀 핵심 기능

### 1. 🧠 AI 기반 초개인화 여행 플래닝
- **취향 프로파일링**: 최초 온보딩 시 15개 질문으로 여행 성향 분석
- **학습형 추천 엔진**: 사용할수록 더 정확해지는 맛집·관광지 추천
- **예산 최적화**: 설정한 예산 내에서 최고의 경험을 제공하는 일정 생성

### 2. 🚆 멀티모달 교통 통합 검색
- **실시간 연계 검색**:
  - 버스 (공공 API 연동)
  - 기차 (KTX, SRT, ITX 등)
  - 비행기 (국내선 및 국제선)
  - 택시/카셰어링 (예상 비용 계산)
- **최적 경로 자동 조합**: 시간/비용/편의성 기준 선택 가능
- **실시간 지연 알림**: 교통편 변동 시 즉시 알림 및 대안 제시

### 3. 🗺️ 3D 시각화 여행 지도
- **Google Maps/Earth 통합**:
  - 이동 경로 애니메이션
  - 추천 장소 3D 마커 표시
  - Street View 미리보기
- **타임라인 뷰**: 시간대별 일정을 지도와 동기화
- **AR 네비게이션**: 현장에서 증강현실로 길찾기 (Phase 2)

### 4. 🍜 큐레이션 맛집 & 명소
- **취향 기반 필터링**:
  - 음식 선호도 (한식/양식/일식/중식/디저트)
  - 분위기 (혼밥 가능/데이트/가족모임/힙한 곳)
  - 가격대 (1만원 이하 ~ 10만원 이상)
- **인플루언서 추천**: 미식가/여행 크리에이터의 큐레이션 (파트너십)
- **실시간 혼잡도**: 현재 대기시간 및 예약 가능 여부 표시

### 5. ⚡ 실시간 적응형 일정 관리
- **지연 자동 대응**: 교통편 지연 시 후속 일정 자동 재조정
- **날씨 연동**: 기상 변화에 따른 실내/실외 활동 자동 교체 제안
- **체력 관리**: 이동 거리 및 활동 강도를 고려한 휴식 시간 자동 배치

### 🎨 독보적인 기술

1. **멀티모달 교통 AI 엔진**:
   - 전국 대중교통 DB 실시간 크롤링
   - 강화학습 기반 최적 경로 알고리즘
   - 예측 모델로 5분 후 ~ 3일 후 최적 경로 제시

2. **취향 학습 추천 시스템**:
   - Collaborative Filtering + Content-Based 하이브리드
   - 리뷰 감성 분석으로 "나와 비슷한 사람들"의 평가 반영
   - 시간대·날씨·동행자 변수 고려

3. **실시간 컨텍스트 어댑터**:
   - 현재 위치·시간·날씨·교통 상황을 실시간 분석
   - 예상치 못한 변수 발생 시 30초 내 대안 제시

## 📊 시장 기회

### 국내 여행 시장 규모
- **2024년 국내 여행 시장**: 약 **35조원** (한국관광공사)
- **여행 앱 MAU**: 2,500만명+ (상위 5개 앱 합산)
- **성장률**: 연평균 12% (포스트 코로나)

### 문제 상황
- 기존 앱들은 "정보 제공"에만 집중 → **의사결정 피로도** 높음
- 교통·숙박·관광이 분리되어 있어 **3~5개 앱을 오가며 계획**
- 90%의 사용자가 일정 계획에 **평균 8시간** 소요

### 우리의 솔루션
- **클릭 3번에 완성되는 여행 계획** (입력 → AI 생성 → 확인)
- **하나의 앱에서 모든 예약 완결** (원스톱 플랫폼)
- **"여행 전" 과 "여행 중" 모두 사용**하는 고정착도 앱
